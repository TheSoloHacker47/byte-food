# byte-food

Every commit to this repo feeds **Byte**, a pocket ESP32-S3 Tamagotchi that dies if I stop coding.

- The first commit of the day gives +40 food. Later commits give +10 joy.
- If Byte has starved into a ghost, one commit brings him back.

Byte checks this repo over the GitHub API every few seconds. The build series is on YouTube at **The Evil Scientist** ([@evilscientistbuilds](https://youtube.com/@evilscientistbuilds)).
